# Agent Skills

这里放 Agent 的「技能卡」。每张 `.md` 是一段领域知识 / 工作流，规划器在生成
工具调用计划时会读取所有**已启用**的技能。

## 格式

```markdown
---
name: 技能名称
description: 一句话说明什么时候用
---

正文：写给规划器的领域说明、参数约定、常见坑。
```

文件名随意；`README.md` 和 `index.md` 不会被当成技能加载。
也支持目录形式：`skills/my-skill/SKILL.md`，适合一个技能带多份参考文件。
技能通过应用头部的「Agent 设置」添加、编辑、启用/禁用或删除，不需要手改
`settings.json`。

## 什么时候生效

- 下一次规划（包括逐步确认时修改单步）读取当前启用的技能；
- 只对**大模型规划**生效；规则引擎不使用技能正文；
- 技能是用户自己的数据，和当前明确指令冲突时以当前指令为准。
